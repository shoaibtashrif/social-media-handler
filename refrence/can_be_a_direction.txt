Combining Audio + Images → Video (Technical Guide)
The Pipeline (What Your Poster Does)
Verse Audio Files (per ayah) + Background Image(s)
         │
         ��
FFmpeg concat (audio) → Single audio track
         │
         ��
FFmpeg: loop image(s) + map audio → MP4 (H.264/AAC)
         │
         ��
Optional: Add text overlays (verse numbers, Arabic/translation)


Core FFmpeg Commands
#### Step 1: Concatenate Verse Audio Files
# Create file list (verse_01.mp3, verse_02.mp3, ...)
cat > audio_list.txt <<EOF
file 'verse_01.mp3'
file 'verse_02.mp3'
file 'verse_03.mp3'
EOF

# Concatenate without re-encoding (fast, lossless)
ffmpeg -f concat -safe 0 -i audio_list.txt -c copy combined_audio.mp3


#### Step 2: Create Video from Image + Audio
# Single static image (loop) + audio
ffmpeg -loop 1 -i background.jpg -i combined_audio.mp3 \
  -c:v libx264 -tune stillimage -c:a aac -b:a 128k \
  -pix_fmt yuv420p -shortest output.mp4

# Multiple images (one per verse) - needs filter_complex
ffmpeg -i combined_audio.mp3 \
  -i verse_01.jpg -i verse_02.jpg -i verse_03.jpg \
  -filter_complex "
    [1:v]scale=1080:1920,setsar=1[v1];
    [2:v]scale=1080:1920,setsar=1[v2];
    [3:v]scale=1080:1920,setsar=1[v3];
    [v1][v2][v3]concat=n=3:v=1:a=0[outv]
  " \
  -map "[outv]" -map 0:a \
  -c:v libx264 -c:a aac -b:a 128k -pix_fmt yuv420p -shortest output.mp4


#### Step 3: Add Text Overlays (Optional)
# Add verse numbers / Arabic text / translation
ffmpeg -i input.mp4 -vf "
  drawtext=text='Surah Al-Mulk 67:21':fontfile=/path/to/Amiri.ttf:fontsize=48:fontcolor=white:x=(w-tw)/2:y=100,
  drawtext=text='وَكَمْ أَهْلَكْنَا قَبْلَهُم مِّن قَرْنٍ':fontfile=/path/to/Amiri.ttf:fontsize=36:fontcolor=white:x=(w-tw)/2:y=200
" -c:a copy output_with_text.mp4

# video_builder.py
import subprocess
from pathlib import Path

def build_quran_video(verse_audio_dir: Path, background_img: Path, output: Path, 
                      surah_name: str, verse_range: str, reciter: str):
    """Build Quran recitation video from per-verse audio files."""
    
    # 1. Sort audio files numerically
    audio_files = sorted(verse_audio_dir.glob("*.mp3"), 
                        key=lambda f: int(f.stem.split("_")[-1]))
    
    # 2. Create concat list
    list_file = verse_audio_dir / "concat_list.txt"
    list_file.write_text("\n".join(f"file '{f.name}'" for f in audio_files))
    
    # 3. Concatenate audio
    combined_audio = verse_audio_dir / "combined.mp3"
    subprocess.run([
        "ffmpeg", "-y", "-f", "concat", "-safe", "0", 
        "-i", str(list_file), "-c", "copy", str(combined_audio)
    ], check=True)
    
    # 4. Build video (static image loop)
    subprocess.run([
        "ffmpeg", "-y", "-loop", "1", "-i", str(background_img),
        "-i", str(combined_audio),
        "-c:v", "libx264", "-tune", "stillimage",
        "-c:a", "aac", "-b:a", "128k",
        "-pix_fmt", "yuv420p", "-shortest",
        "-metadata", f"title={surah_name} {verse_range}",
        "-metadata", f"artist={reciter}",
        "-metadata", "comment=Quran Recitation",
        str(output)
    ], check=True)
    
    print(f"��� Video created: {output}")

# https://api.quran.foundation/ - Modern API
import requests

def get_verse_audio(surah: int, ayah: int, reciter: str = "ar.alafasy") -> str:
    """Returns direct MP3 URL for a verse."""
    url = f"https://api.quran.foundation/ayah/{surah}/{ayah}"
    data = requests.get(url).json()
    return data["audio"][reciter]["url"]

# Usage
for ayah in range(21, 24):
    print(get_verse_audio(67, ayah))

FFmpeg Command Explained
-loop 1 -i image.jpg
• Purpose: Loop single image infinitely

-i audio.mp3
• Purpose: Input audio

-c:v libx264
• Purpose: H.264 encoder

-tune stillimage
• Purpose: Optimize for static image (tiny file size)

-c:a aac -b:a 128k
• Purpose: AAC audio at 128kbps

-pix_fmt yuv420p
• Purpose: Standard pixel format (IG compatible)
 (1/3)
-shortest
• Purpose: Stop encoding when shortest stream ends (audio)

-vf scale=1080:1080...
• Purpose: Force 1080x1080 with padding (IG Reels format)
